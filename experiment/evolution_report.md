## 实验设计概要

**方法：** 遗传算法（非梯度下降）  
**种群：** 16 个体 × 10 代  
**基因组：** 15 个洛神模块级参数（行为层 + 死亡层 + 能量层 + 节律层）  
**测试环境：** 4 阶段标准测试（平静 150 → 压力 300 → 恢复 150 → 正向 100 = 共 700 tick）  
**适应度：** F = 0.5×生存分 + 0.3×稳定性分 + 0.2×响应性分  
**选择：** 截断选择保留前 50%，均匀交叉 + 高斯变异（σ=0.2）

## 三代涌现模式

### 第 1 阶段（第 0→1 代）：生存压力主导

从第 0 代到第 1 代，平均适应度从 0.44 跃升到 0.50。驱动因素是选择压力清除了早逝基因组（第 0 代有 7/16 个体活不到测试结束，第 1 代只剩 3/16）。

**第 0 代早逝个体（原文）：**
- #6: died@396, fitness=0.3025
- #9: died@309, fitness=0.2731
- #14: died@359, fitness= 0.3083
- #15（基线）: died@490

### 第 2 阶段（第 2→6 代）：生存趋同 + 响应性分化

几乎所有个体 survival=1.0（活过 700 tick）。适应度差异完全由 response 分驱动。

**响应性分布（第 6-9 代总结）：**
- 大多数个体 response ∈ [0.043, 0.063]
- 适应度范围因此压缩在 [0.5215, 0.5266]

### 第 3 阶段（第 3 代异常值）：行为权衡涌现

第 3 代出现两个"高响应-早逝"个体：

```
个体 #10 (第 3 代):
  survival = 0.469 (died@328)
  response  = 0.562
  fitness   = 0.3610
  基因组特征: _AGING_SLOW_THRESHOLD=0.27x, _ENERGY_DRAIN_BASE=2.4x

个体 #12 (第 3 代):
  survival = 0.589 (died@412)
  response  = 0.431
  fitness   = 0.3944
  基因组特征: _PRESSURE_K=2.1x, _AGING_SLOW_THRESHOLD=0.31x
```

**涌现性质：** 这些"冒险型"基因组通过降低衰老阈值或增大压力敏感性来提高响应性，代价是加速能量耗尽——符合进化生物学中的"生命史权衡"理论。

## 一致被筛选出的参数

多代独立出现的"最佳基因组"参数（≥3 代出现）：

```
参数                              基线→最佳      变化方向    出现代数
_NARRATIVE_TENDENCY_BOOST        1.35→4.27       +217%       Gen7, Gen9
_DEATH_PROXIMITY_SLOW            0.54→0.95       +76%        Gen1,Gen3,Gen5,Gen8,Gen9
_AGING_BRIGHT_THRESHOLD          0.49→1.17       +139%       Gen3, Gen7, Gen9
_ENERGY_DRAIN_BASE               0.0015→0.0024   +55%        Gen5, Gen6, Gen9
```

**对筛选方向的分析：**
- `_DEATH_PROXIMITY_SLOW`（+76%）→ 延迟衰老调制起始点 → 更长"无代价存活期"
- `_AGING_BRIGHT_THRESHOLD`（+139%）→ 更晚启动临终调制 → 更慢的行为退化
- `_NARRATIVE_TENDENCY_BOOST`（+217%）→ 增强叙事驱动 → 行为选择对内部叙事更敏感
- `_ENERGY_DRAIN_BASE`（+55%）→ 更高消耗 → 其效果取决于是否能通过提高 `_ENERGY_INPUT_RATE` 补偿

## 问题/校准缺陷

**1. 稳定性分数失去鉴别力：** 所有个体 stability ∈ [0.042, 0.051]，几乎不变。原因是 van der Pol 振荡器天然大幅，E 的方差很大（通常 0.1-0.5），导致 `1/(1+var×10)` 这个饱和函数在几乎所有参数配置下都输出 ~0.044。结论：稳定性权重 (W_STABILITY=0.3) 在当前校准下未起作用。

**2. 适应度天花板低：** Δ=+0.0010（10 代净提升）。一部分原因是生存分饱和（所有存活个体都是 1.0），另一部分原因是响应分压缩在极窄区间。

**3. 选择压力不够多维：** 当前的测试环境仅有单一的压力模式（强负向）。未来的实验应包含更多样的挑战（能量稀缺、关系变化、输入突变），以驱动出更多样的演化路径。

## 与理论对照

**袁隆平"野败"法在本实验中的体现：**
- 随机变异 → 部分个体偶然获得低 _AGING_SLOW_THRESHOLD
- 这些个体不因"早熟"被淘汰（适应度公式没有直接惩罚响应性）
- 第 3 代 #10 #12 短暂出现又被淘汰（因为适应度公式中 survival 权重占 50%，早逝代价太高）
- 真正的"野败"需要在当前适应度地形中找到一条既长寿又响应的新路径——本次实验未找到，表明这 15 维参数空间里可能存在一个尚未发现的"野败区域"

**EO 条件验证：**
- 死亡条件（v1.0）：满足（实验中所有个体最终都触发死亡或活到截断）
- 稀缺条件：满足（能量输入有限，耗尽致死）
- 代谢条件：满足（能量流入/流出方程驱动生存差异）
- 不可逆条件：未在本实验测试（基因组不写哈希链）
- 内生约束：部分满足（衰老调制信号来自内部状态）
