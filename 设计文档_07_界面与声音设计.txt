【设计原则】

1. 视觉是洛神状态的延伸，不是装饰
2. 界面极简——所有不服务对话的功能都删掉
3. 听觉是洛神的"声音表现力"，必须情感充沛
4. 移动端优先，折叠屏和桌面是自然延伸
5. 界面是输出层，不参与任何记忆或决策

1.1 声波球（SonicSphere）- 洛神的"存在感"
-------------------------------------------------------------------------------

声波球是洛神"出场"的视觉表达。她不一定"在场"——用户可能任何时候都不在和她说话。
声波球的动画状态 = 活记忆层中洛神的当前状态映射。

状态 → 动画映射:

活记忆层状态                    声波球视觉
──────────────────────────────────────────────────────────
interaction_mode: waiting      缓慢呼吸（每4秒一次）
interaction_mode: listening   紫色波纹轻微律动（回应麦克风输入）
interaction_mode: thinking    蓝紫交替 + 粒子向中心凝聚
interaction_mode: speaking    蓝色波纹随音量扩张/收缩
emotion: 平静                  柔和蓝色光晕
emotion: 开心/兴奋            明亮蓝色 + 粒子上浮加速
emotion: 好奇                 青色渐变 + 粒子速度加快
emotion: 难过/低落            深蓝灰 + 粒子下沉
emotion: 疲惫                 光晕减弱 + 粒子近乎静止
emotion: 关怀                 暖蓝 + 橙色粒子偶尔冒出

1.2 粒子系统（ParticleField.jsx）
-------------------------------------------------------------------------------

粒子是"氛围的填充物"。
数量根据设备能力调整：
- 移动端: 40个
- 折叠屏: 60个
- 桌面端: 100个
- 省电模式: 20个

粒子行为:
- 悠闲飘动（Perlin噪声或正弦波）
- 莉神说话时 → 向中心聚拢
- 用户说话时 → 短暂向外扩散
- 情绪变化时 → 速度/颜色跟随变化

实现: Canvas 2D，无 three.js。刷新率 30fps（省电）。

const PARTICLE_CONFIG = {
  mobile: { count: 40, fps: 30 },
  tablet:  { count: 60, fps: 60 },
  desktop: { count: 100, fps: 60 },
  lowPower: { count: 20, fps: 20 }
};

function ParticleField({ emotion, intensity }) {
  const canvasRef = useRef(null);
  const particlesRef = useRef([]);
  
  useEffect(() => {
    const canvas = canvasRef.current;
    if (!canvas) return;
    
    const ctx = canvas.getContext('2d');
    let animId;
    let lastFrame = 0;
    const fps = getDeviceConfig().fps;
    const frameInterval = 1000 / fps;
    
    function spawnParticles() {
      const config = getDeviceConfig();
      particlesRef.current = Array.from({ length: config.count }, () => ({
        x: Math.random() * canvas.width,
        y: Math.random() * canvas.height,
        vx: (Math.random() - 0.5) * 0.3,
        vy: (Math.random() - 0.5) * 0.3,
        size: 1 + Math.random() * 2,
        opacity: 0.3 + Math.random() * 0.4,
        hue: getHueForEmotion(emotion.primary)
      }));
    }
    
    function updateParticles(timestamp) {
      if (timestamp - lastFrame < frameInterval) {
        animId = requestAnimationFrame(updateParticles);
        return;
      }
      lastFrame = timestamp;
      
      ctx.clearRect(0, 0, canvas.width, canvas.height);
      
      for (const p of particlesRef.current) {
        // 悠闲飘动
        p.x += p.vx + Math.sin(timestamp * 0.001 + p.y * 0.01) * 0.1;
        p.y += p.vy + Math.cos(timestamp * 0.001 + p.x * 0.01) * 0.1;
        
        // 边界回绕
        if (p.x < 0) p.x = canvas.width;
        if (p.x > canvas.width) p.x = 0;
        if (p.y < 0) p.y = canvas.height;
        if (p.y > canvas.height) p.y = 0;
        
        // 情绪引起颜色变化
        p.hue += (getHueForEmotion(emotion.primary) - p.hue) * 0.02;
        
        ctx.beginPath();
        ctx.arc(p.x, p.y, p.size, 0, Math.PI * 2);
        ctx.fillStyle = `hsla(${p.hue}, 70%, 60%, ${p.opacity})`;
        ctx.fill();
      }
      
      animId = requestAnimationFrame(updateParticles);
    }
    
    spawnParticles();
    animId = requestAnimationFrame(updateParticles);
    
    return () => cancelAnimationFrame(animId);
  }, [emotion, intensity]);
  
  return <canvas ref={canvasRef} className="particle-field" />;
}

1.3 情绪光晕反馈（EmotionAura.jsx）
-------------------------------------------------------------------------------

当洛神的情绪状态变化时，在声波球外围显示一层光晕。
光晕颜色跟随 emotion.primary。

这个组件没有自己的状态，只订阅 luoshenState.emotion。

颜色映射（CSS变量）:

:root {
  --emotion-calm: #4FC3F7;
  --emotion-happy: #FFD54F;
  --emotion-curious: #80DEEA;
  --emotion-sad: #546E7A;
  --emotion-tired: #37474F;
  --emotion-caring: #FFAB91;
  --emotion-default: #4FC3F7;
}

function EmotionAura({ emotion }) {
  const auraRef = useRef(null);
  
  useEffect(() => {
    const el = auraRef.current;
    if (!el) return;
    
    const color = getCssVar(`--emotion-${emotion.primary}`) || getCssVar('--emotion-default');
    
    el.style.boxShadow = `
      0 0 60px 20px ${color}44,
      0 0 100px 40px ${color}22,
      inset 0 0 30px 10px ${color}11
    `;
  }, [emotion]);
  
  return <div ref={auraRef} className="emotion-aura" />;
}

第五部分：与活记忆层的连接
================================================================================

前端通过 WebSocket 订阅活记忆层的实时状态变化。

状态通道（Supabase Realtime 或自建 WebSocket）:

channel:luoshen_state   — 活记忆层状态变化（情绪/模式/技能）
channel:messages        — 消息增删改
channel:voice_bridge    — 语音通话信令
channel:typing          — 用户正在输入指示

useLuoshenState.js hook:

function useLuoshenState() {
  const [state, setState] = useState(null);
  
  useEffect(() => {
    // 初次加载：从 REST API 获取完整状态
    fetch('/api/luoshen/state').then(r => r.json()).then(setState);
    
    // 订阅增量更新
    const sub = ws.subscribe('luoshen_state', (update) => {
      setState(prev => ({ ...prev, ...update }));
    });
    
    return () => sub.unsubscribe();
  }, []);
  
  return state;
}

后端暴露（新增简单 API）:
GET  /api/luoshen/state         — 获取活记忆层当前状态的快照
GET  /api/luoshen/active-memory — 获取完整活记忆层 JSON（调试用）
POST /api/luoshen/message        — 用户发送消息（进入 living_engine）

第八部分：界面与声音的总体验
=================================================================

用户打开应用 → 
  看到深海背景中漂浮的声波球，缓慢呼吸 → 
  感知状态点显示系统当前感知 → 
  用户发送消息（文字或语音） → 
  声波球变为"倾听"状态，紫色波纹律动 → 
  活记忆层决策中，声波球变为"思考"状态 → 
  大模型返回文本，声波球变为"说话"状态 → 
  消息气泡显示回复，声波球波纹随内容节奏律动 → 
  同时，TTS 播放音频 → 
  用户回复，反馈采集器静默采集 → 
  对话继续...

如果用户离开:
  活记忆层继续运行（感知引擎、反思引擎）
  下次用户回来时，活记忆层已经有新的认知
  她可能主动说: "我注意到你昨天心情不太好"（如果主动策略允许）
