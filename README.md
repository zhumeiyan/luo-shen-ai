# 差和互换迭代的极限状态

**作者：** 朱美岩
**日期：** 2026 年 9 月

---

## 摘要

本文研究定义在 ℝⁿ（n ≥ 2）上的一对向量按"和–差加权互换"生成的离散动力系统。本文证明：

（一）迭代等价于二项递推 a′ = b + αa，b′ = b − αa；
（二）第一拍后，迭代落入吸收区 D = (0, 1) × (−1, 0)，此后严格保持；
（三）D 内存在唯一不动点 (r\*, c\*)，r\* = 1/T，T 是三波那契常数（T³ − T² − T − 1 = 0 的唯一实根，T ≈ 1.8392867552141612）；
（四）该不动点为局部稳定焦点，形状误差范数收敛模为 0.593；
（五）状态空间 (a, b) 冻结形状后每步收缩 √2/T ≈ 0.768892375，每步旋转 32.593963°。

全局收敛由局部严格证明加数值验证给出，完整解析证明留作后续工作。三个极限量的解析表达式与数值结果吻合至九位有效数字。

**关键词：** 三波那契常数；离散动力系统；不动点；稳定焦点；差和互换

---

## 一、符号定义

设 a, b ∈ ℝⁿ（n ≥ 2）为两个实向量。定义：

```
δ = b − a                     (差)
σ = a + b                     (和)
d = ‖δ‖                       (差的范数)
s = ‖σ‖                       (和的范数)
α = (s − d) / (s + d)         (加权系数)
```

定义迭代：

```
a' = (s·σ + d·δ) / (s + d)
b' = (s·δ + d·σ) / (s + d)
```

记第 k 轮为 (aₖ, bₖ)，对应 δₖ = bₖ − aₖ，σₖ = aₖ + bₖ，dₖ = ‖δₖ‖，sₖ = ‖σₖ‖。

定义两个无量纲量：

```
rₖ = dₖ / sₖ
cₖ = (σₖ · δₖ) / (‖σₖ‖ · ‖δₖ‖)
```

**注：** 本文结论不依赖空间维度 n，只要 n ≥ 2。选择 n = 3 仅为编码方便。

---

## 二、前置条件

取初值 a₀, b₀ ∈ ℝⁿ，满足：

**(C1)** a₀ ≠ b₀
**(C2)** a₀ · b₀ ≠ 0
**(C3)** a₀ 与 b₀ 不共线

---

## 三、主要结果

### 3.1 已证部分

**定理 1（迭代化简）** 迭代等价于

```
a' = b + α·a ,    b' = b − α·a ,    α = (s − d)/(s + d)
```

**定理 2（吸收区）** 在上述条件下，第一拍后

```
(r₁, c₁) ∈ (0, 1) × (−1, 0)
```

此后迭代严格保持在此区域内。

**定理 3（不动点）** 吸收区内存在唯一比例不动点

```
r* = 1/T ,    c* = −(1 − r*²)/(2r*)
```

其中 T 是 T³ − T² − T − 1 = 0 的唯一实根，T ≈ 1.8392867552141612，r\* ≈ 0.5436890126920763，c\* ≈ −0.647798871。

**定理 4（局部稳定）** 不动点 (r\*, c\*) 为稳定焦点。其 (r, c) 映射在 (r\*, c\*) 处的 Jacobian 特征值模为

```
|λ_{r,c}| = √det(J) ≈ 0.593297 < 1
```

此模数是**误差范数** |Δ| = √((r − r\*)² + (c − c\*)²) 的每步衰减率。平方误差 V = |Δ|² 的每步衰减率为 |λ_{r,c}|² ≈ 0.352。

### 3.2 数值结论

**命题 5（全局收敛，混合证明）** 取任意满足 (C1)(C2)(C3) 的初值，迭代趋向 (r\*, c\*)。

证明分两部分：

- **(i) 局部收敛**（严格证明）：由定理 4，不动点邻域内收敛。
- **(ii) 进入邻域**（数值验证）：500 个随机初值 × 20 万步数值验证表明，满足条件的初值在有限步内进入 V < 10⁻¹⁰ 的邻域。

完整解析证明留作后续工作。

### 3.3 极限量

由定理 3、4 直接推出：

```
‖δₖ‖ / ‖σₖ‖            →  1/T     ≈ 0.543689013
‖σₖ₊₁‖ / ‖σₖ‖          →  √2 / T  ≈ 0.768892375
∠(aₖ, aₖ₊₁)            →  32.593963°
```

---

## 四、完整证明

### 第一节 化简为二项递推

由定义：

```
a' = (s·σ + d·δ) / (s + d)
b' = (s·δ + d·σ) / (s + d)
```

**计算 a′ + b′：**

```
a' + b' = (s·σ + d·δ + s·δ + d·σ) / (s + d)
        = ((s + d)·σ + (s + d)·δ) / (s + d)
        = σ + δ = 2b
```

故

```
a' + b' = 2b                                   (1.1)
```

**计算 a′ − b′：**

```
a' − b' = (s·σ + d·δ − s·δ − d·σ) / (s + d)
        = ((s − d)·σ + (d − s)·δ) / (s + d)
        = (s − d)·(σ − δ) / (s + d)
        = (s − d) · 2a / (s + d) = 2α·a         (1.2)
```

**联立 (1.1)(1.2)：**

```
a' = b + α·a ,    b' = b − α·a                  (1.3)
α = (s − d) / (s + d)                          (1.4)
```

定理 1 证毕。

---

### 第二节 换到 (σ, δ) 坐标

由 (1.3)：

```
σ' = a' + b' = 2b = σ + δ                      (2.1)
δ' = b' − a' = −2α·a = α(δ − σ)                (2.2)
```

故

```
σ' = σ + δ ,    δ' = α·(δ − σ)                 (2.3)
```

---

### 第三节 第一拍后进入吸收区，且严格保持

记 r = d/s，c = (σ·δ)/(s·d)。

**3.1 第一拍后 c′ < 0**

```
σ' · δ' = (σ + δ) · α(δ − σ) = α(|δ|² − |σ|²) = −(s − d)²
```

等号当且仅当 s = d，即 a·b = 0，由 C2 排除。故 σ′·δ′ < 0。

σ′ = 2b ≠ 0（否则 a·b = 0，与 C2 矛盾）；δ′ = α(δ − σ) ≠ 0（否则 a·b = 0 或 a = 0，均与 C2 矛盾）。故 c′ < 0。

**3.2 第一拍后 r′ < 1**

```
(r')² = ((1 − r)/(1 + r))² · (1 + r² − 2rc) / (1 + r² + 2rc)
```

(r′)² < 1 等价于 4r(1 + r²)(1 + c) > 0，在 r > 0，c > −1 时严格成立。

c₀ = −1 当且仅当 σ₀ ∥ δ₀ 且反向，即 (a+b) ∥ (b−a)，推得 a ∥ b，与 C3 矛盾。

**3.3 吸收区的严格保持**

第一拍后，(r₁, c₁) ∈ (0, 1) × (−1, 0)。证明后续保持：

**(i) c′ ∈ (−1, 0) 的保持。**

在 D 内，由 c² < 1：

```
√((1 + r²)² − 4r²c²) > √((1 + r²)² − 4r²) = 1 − r² > 0
```

故

```
|c'| = (1 − r²) / √((1 + r²)² − 4r²c²) < 1
```

且 c′ < 0，故 c′ ∈ (−1, 0)。

**(ii) r′ ∈ (0, 1) 的保持。**

r′ < 1 已证。r′ > 0 等价于 δ′ ≠ 0。δ′ = α(δ − σ)，α > 0（因 r < 1）。δ = σ 等价于 a = 0，与 C2 矛盾。故 r′ > 0。

定理 2 证毕。

---

### 第四节 吸收区内 (r, c) 的迭代公式

在 D 内 r ∈ (0, 1)，α = (1 − r)/(1 + r) > 0。

```
r' = ((1 − r)/(1 + r)) · √((1 + r² − 2rc) / (1 + r² + 2rc))    (4.1)
c' = −(1 − r²) / √((1 + r²)² − 4r²c²)                          (4.2)
```

---

### 第五节 不动点方程

**5.1 解 c 方程**

令 c′ = c，两边平方：

```
c²((1 + r²)² − 4r²c²) = (1 − r²)²
```

验证 c = −(1 − r²)/(2r) 满足。故

```
c*(r) = −(1 − r²) / (2r)                       (5.1)
```

**5.2 代回 r 方程**

在 (5.1) 下：

```
2r·c* = r² − 1
1 + r² − 2r·c* = 2
1 + r² + 2r·c* = 2r²
√((1 + r² − 2r·c*)/(1 + r² + 2r·c*)) = 1/r
```

代入 (4.1)：

```
r' = (1 − r) / (1 + r) · 1/r                   (5.2)
```

令 r′ = r：

```
r³ + r² + r − 1 = 0                            (5.3)
```

---

### 第六节 解出根

令 T = 1/r，得

```
T³ − T² − T − 1 = 0                            (6.1)
```

唯一实根证明：f(x) = x³ − x² − x − 1，f′(x) = (3x + 1)(x − 1)，x > 1 时 f′ > 0，f(1) = −2 < 0，lim f = +∞，故唯一实根。

```
T ≈ 1.8392867552141612
r* = 1/T ≈ 0.5436890126920763
c* = −(1 − r*²)/(2r*) ≈ −0.647798871
```

定理 3 证毕。

---

### 第七节 局部稳定

在 (r\*, c\*) 处，映射 (4.1)(4.2) 的 Jacobian 数值计算（中心差分，步长 10⁻⁸）：

```
J = [ −1.124094   −0.647798 ]
    [  1.271796    0.419727 ]

tr(J) = −0.704367
det(J) = 0.352001
```

复特征值：

```
λ_{r,c} = −0.352184 ± 0.477467i
|λ_{r,c}| = √0.352001 ≈ 0.593297
```

**误差范数的衰减率与平方误差的衰减率：**

设误差向量 Δ = (r − r\*, c − c\*)。由线性化理论，渐近意义下

```
|Δ_{n+1}| ≈ |λ_{r,c}| · |Δ_n|
```

即误差**范数**每步乘 |λ_{r,c}| ≈ 0.593。

平方误差 V = |Δ|² 每步乘 |λ_{r,c}|² ≈ 0.352。

两个衰减率对应两个不同的量，不应混用。

---

### 第八节 全局收敛

**8.1 域内唯一不动点**

由第五节，不动点必要条件为 r³ + r² + r − 1 = 0 且 c = c\*(r)。正根唯一。故 (r\*, c\*) 是 D 内唯一不动点。

**8.2 局部收敛（严格证明）**

设 V(r, c) = (r − r\*)² + (c − c\*)²。F 在 (r\*, c\*) 处 Jacobian 谱半径 |λ| ≈ 0.593 < 1。由谱半径连续性，存在 ε > 0 使得对 B = {V < ε} 内所有点，ρ(J_F(r, c)) ≤ 1 − δ < 1。

由范数与谱半径的等价性，存在范数 ‖·‖\* 使 ‖J_F‖\* ≤ 1 − δ/2 < 1。由 Banach 压缩映射原理，B 内轨道收敛到 (r\*, c\*)。

**8.3 数值证据：任意初值有限步进入 B**

**样本设置：** 500 个随机初值 (a₀, b₀)，各分量独立取自 N(0, 1)。

**邻域参数：** 取 ε = 10⁻¹⁰。经数值验证，在 V < 10⁻¹⁰ 区域内，Jacobian 谱半径 ≤ 0.594。

**步数估计：**

- 目标：V < 10⁻¹⁰，等价于 |Δ| < 10⁻⁵。
- 渐近衰减率：|Δ| 每步乘 0.593。
- 理论步数：log(10⁻⁵) / log(0.593) ≈ 22 步。
- 实测：中位数 45 步，最大值 52 步。

实测大于理论值，因为初始阶段（远离不动点）Jacobian 谱半径大于 0.593，瞬态收敛慢于渐近。两者量级一致。

**结果：** 全部 500 个轨道在 52 步内进入 V < 10⁻¹⁰。进入后落点标准差：r 方向 < 10⁻¹⁵，c 方向 < 10⁻¹⁵。

**8.4 全局收敛的完成**

由 8.2（局部收敛）和 8.3（500 个初值进入邻域），满足 (C1)(C2)(C3) 的初值收敛到 (r\*, c\*)。

**注：** 完整解析证明留作后续工作。两条路径：

- **路径 A：** 显式计算 sup_D ρ(J(r, c)) < 1。
- **路径 C：** 构造显式 Lyapunov 函数 V(r, c) = (r − r\*)² + λ(c − c\*)²，选取 λ 使 V 沿迭代负定。

---

### 第九节 极限量的推导

**9.1 差和长度比极限**

rₖ → r\* = 1/T：

```
‖δₖ‖ / ‖σₖ‖ → 1/T ≈ 0.543689013
```

**9.2 收缩率极限**

由 α\* = r\*²，在 (r\*, c\*) 处 1 + r\*² + 2r\*c\* = 2r\*²，故

```
‖σₖ₊₁‖ / ‖σₖ‖ → r*√2 = √2/T ≈ 0.768892375
```

**9.3 旋转角极限**

形状冻结后，状态空间 (a, b) 的线性化矩阵：

```
[a']   [α*   1] [a]
[b'] = [−α*  1] [b]
```

特征多项式 λ² − (1 + α\*)λ + 2α\* = 0，特征值模 √(2α\*) = √2/T，相位角

```
cos θ = (1 + r*²) / (2√2 · r*)
θ = arccos(0.8425092) = 32.593963°
```

## 七、讨论

**7.1 与三波那契常数的关系**

不动点方程 r³ + r² + r − 1 = 0 的唯一正根 r\* = 1/T。

**7.2 关于维度的说明**

本文结论适用于任意 n ≥ 2。

**7.3 三层收敛速率的区分**

本文涉及三个不同的收敛速率，应严格区分：

| 速率 | 数值 | 含义 |
|---|---|---|
| \|λ_{r,c}\| | 0.593 | (r, c) 形状空间，误差范数 \|Δ\| 每步衰减率 |
| \|λ_{r,c}\|² | 0.352 | (r, c) 形状空间，平方误差 V 每步衰减率 |
| \|λ_{a,b}\| | 0.7689 | (a, b) 状态空间，形状冻结后的每步收缩率 |

三者来源不同、含义不同。误用会造成量级偏差。

**7.4 后续工作**

（一）严格解析证明进入邻域：路径 A 或路径 C。

（二）应用：记忆衰减、内部节拍、异常检测。

## 八、结论

本文给出一组定义在 ℝⁿ（n ≥ 2）上的和–差互换迭代。证明：

（一）迭代等价于二项递推 a′ = b + αa，b′ = b − αa；
（二）第一拍后进入吸收区 D = (0, 1) × (−1, 0)，此后严格保持；
（三）D 内存在唯一不动点 (r\*, c\*)，r\* = 1/T 由三波那契常数 T 决定；
（四）不动点为局部稳定焦点，误差范数收敛模约 0.593。

三个极限量的解析表达式与数值结果吻合至九位有效数字。全局收敛通过局部严格证明加 500 个初值的数值验证给出，完整解析证明留作后续工作。
